# XAuPlayer Web

Веб-версия аудиоплеера XAuPlayer для прослушивания аудиокниг в браузере.

## 🚀 Возможности

- 📚 **Просмотр библиотеки книг** - Просмотр всех доступных аудиокниг с поиском и фильтрацией
- 🎧 **Воспроизведение аудио** - Потоковое воспроизведение аудиокниг прямо в браузере
- 📊 **Отслеживание прогресса** - Автоматическое сохранение прогресса прослушивания
- 🏷️ **Статусы книг** - Управление статусами (желаемое, слушаю, прослушано, брошено)
- 👤 **Управление аккаунтом** - Просмотр информации об аккаунте и устройствах
- ⚙️ **Настройки** - Настройка сервера и параметров воспроизведения
- 📱 **Адаптивный дизайн** - Отлично работает на ПК и мобильных устройствах

## 📋 Требования

- Современный браузер с поддержкой ES6 модулей (Chrome, Firefox, Safari, Edge)
- Доступ к серверу XAuPlayer API

## 🔧 Установка и развертывание

**⚠️ ВАЖНО:** Приложение **НЕ МОЖЕТ** работать при открытии файла напрямую через `file://` из-за ограничений CORS для ES6 модулей. Обязательно используйте веб-сервер!

### ⚡ Быстрый запуск (рекомендуется)

**Windows:**
```bash
cd web-app
start.bat
```

**Linux/Mac:**
```bash
cd web-app
chmod +x start.sh
./start.sh
```

Скрипты автоматически найдут свободный порт (начиная с 8000).  
Откройте в браузере адрес, который покажет скрипт (обычно `http://localhost:8000`)

### Вариант 1: Python HTTP сервер

```bash
cd web-app
python -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000`

**Если порт 8000 занят, попробуйте другой:**
```bash
python -m http.server 3000
# или
python -m http.server 5000
```

### Вариант 2: Node.js сервер

```bash
cd web-app
npx http-server -p 8000
```

Затем откройте в браузере: `http://localhost:8000`

**Если порт занят, используйте другой:**
```bash
npx http-server -p 3000
```

### Вариант 3: Простой веб-сервер

1. Скопируйте папку `web-app` на ваш веб-сервер
2. Настройте веб-сервер для обслуживания статических файлов
3. Откройте в браузере

### Вариант 4: Nginx

Добавьте в конфигурацию Nginx:

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/web-app;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### Вариант 5: Apache

Создайте файл `.htaccess` в папке `web-app`:

```apache
RewriteEngine On
RewriteBase /
RewriteRule ^index\.html$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.html [L]
```

## ⚙️ Настройка

### Настройка URL сервера

1. Откройте приложение в браузере
2. Перейдите в "Настройки"
3. Введите URL вашего сервера API (например: `http://localhost:8000`)
4. Нажмите "Сохранить"
5. Перезагрузите страницу

Или измените значение по умолчанию в `js/api.js`:

```javascript
constructor(baseUrl = 'http://your-server:8000') {
```

### Настройка CORS на сервере

Убедитесь, что ваш сервер API настроен для работы с CORS. В FastAPI это может выглядеть так:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # В продакшене укажите конкретные домены
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 📱 Использование

1. **Регистрация/Вход**
   - При первом запуске зарегистрируйте новый аккаунт или войдите существующим
   - Email и пароль должны совпадать с данными на сервере
   - При отсутствии токена автоматически отображается страница входа

2. **Просмотр книг**
   - На вкладке "Книги" просматривайте доступные аудиокниги
   - Используйте поиск для быстрого поиска по названию или автору (Ctrl+K)
   - Фильтруйте книги по статусам: Все, Слушаю, Желаемые, Прослушано

3. **Воспроизведение**
   - Нажмите на книгу для начала воспроизведения
   - Используйте элементы управления для паузы, перемотки, переключения глав
   - Изменяйте скорость воспроизведения (0.5x - 2x)
   - Прогресс автоматически сохраняется каждые 5 секунд

4. **Аккаунт**
   - Просматривайте статистику прослушивания
   - Управляйте подключенными устройствами

5. **Настройки**
   - Настройте URL сервера
   - Выберите скорость воспроизведения по умолчанию
   - Просмотрите список горячих клавиш

## ⌨️ Горячие клавиши

### Навигация
- `Ctrl+1` (или `Cmd+1` на Mac) - Перейти к Книгам
- `Ctrl+2` (или `Cmd+2` на Mac) - Перейти к Плееру
- `Ctrl+3` (или `Cmd+3` на Mac) - Перейти к Аккаунту
- `Ctrl+4` (или `Cmd+4` на Mac) - Перейти к Настройкам
- `Ctrl+K` (или `Cmd+K` на Mac) - Фокус на поиск книг
- `Ctrl+Q` (или `Cmd+Q` на Mac) - Выход из системы
- `?` - Показать справку по горячим клавишам

### Плеер
- `Пробел` - Воспроизведение/Пауза
- `←` (Стрелка влево) - Назад на 10 секунд
- `→` (Стрелка вправо) - Вперед на 10 секунд
- `↑` (Стрелка вверх) - Предыдущая глава
- `↓` (Стрелка вниз) - Следующая глава
- `F` - Перейти к плееру

**Примечание:** Горячие клавиши не работают когда фокус находится в поле ввода текста.

## 🔒 Безопасность

- Токены доступа хранятся в `localStorage` браузера
- При выходе токены удаляются
- Все запросы к API используют Bearer токены
- При истечении токена выполняется автоматическое обновление

## 🐛 Решение проблем

### Ошибка CORS
- Убедитесь, что сервер настроен для работы с CORS
- Проверьте URL сервера в настройках

### Книги не загружаются
- Проверьте подключение к серверу
- Убедитесь, что токен авторизации валиден
- Проверьте консоль браузера на наличие ошибок

### Аудио не воспроизводится
- Убедитесь, что формат аудио поддерживается браузером
- Проверьте, что сервер доступен и возвращает аудиофайлы
- Проверьте права доступа к аудиофайлам на сервере

### Токен истек
- Выйдите и войдите снова
- Приложение должно автоматически обновить токен при возможности

## 📝 Примечания

- Приложение использует ES6 модули, поэтому требуется современный браузер

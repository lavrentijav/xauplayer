# Быстрый старт

## ⚠️ ВАЖНО: Не открывайте index.html напрямую!

Приложение использует ES6 модули, которые **не работают** при открытии файла через `file://` протокол.

## ✅ Правильный способ запуска:

### Windows:
1. Откройте командную строку в папке `web-app`
2. Запустите: `start.bat`
3. Скрипт автоматически найдет свободный порт
4. Откройте в браузере адрес, который покажет скрипт (обычно `http://localhost:8000`)

### Linux/Mac:
1. Откройте терминал в папке `web-app`
2. Запустите: `chmod +x start.sh && ./start.sh`
3. Скрипт автоматически найдет свободный порт
4. Откройте в браузере адрес, который покажет скрипт (обычно `http://localhost:8000`)

### Альтернатива (если скрипты не работают):

**Python:**
```bash
cd web-app
python -m http.server 8000
```

Если порт 8000 занят, попробуйте другой:
```bash
python -m http.server 3000
# или
python -m http.server 5000
```

**Node.js:**
```bash
cd web-app
npx http-server -p 8000
```

Если порт занят:
```bash
npx http-server -p 3000
```

Затем откройте в браузере соответствующий адрес (например: `http://localhost:8000`)

## 🔧 Настройка сервера API

1. После открытия приложения нажмите на иконку ⚙️ (шестеренка) в правом верхнем углу
2. Введите URL вашего API сервера (например: `http://localhost:8000`)
3. Нажмите "Проверить подключение"
4. Если проверка успешна, нажмите "Сохранить"
5. Теперь можно войти или зарегистрироваться

## ❌ Что НЕ делать:

- ❌ Не открывайте `index.html` двойным кликом
- ❌ Не используйте `file://` протокол
- ❌ Не открывайте файлы напрямую из проводника

## ✅ Что делать:

- ✅ Используйте веб-сервер (Python, Node.js, или любой другой)
- ✅ Открывайте через `http://localhost:8080`
- ✅ Используйте скрипты `start.bat` или `start.sh`

# Вклад в XAuPlayer

Спасибо за интерес к проекту! Ниже — короткие правила, чтобы всем было удобно.

## С чего начать

1. Сделайте форк и создайте ветку от `main`:
   `git checkout -b feature/название`.
2. Убедитесь, что проект собирается:
   `./gradlew assembleDebug`.
3. Внесите изменения, придерживаясь стиля окружающего кода
   (Kotlin, Jetpack Compose, Material 3).
4. Откройте Pull Request в `main` с понятным описанием.

## Требования к окружению

- JDK 17
- Android SDK (compileSdk 35, minSdk 26)
- Gradle через wrapper (`./gradlew`)

## Стиль и коммиты

- Сообщения коммитов — в повелительном наклонении, кратко и по делу
  (`Add ...`, `Fix ...`, `Refactor ...`).
- Не коммитьте `local.properties`, keystore, `.env` и любые секреты.
- Держите изменения сфокусированными: один PR — одна задача.

## CI

Каждый push и PR запускает workflow **Build APK**
(`.github/workflows/android-build.yml`), который собирает debug- и
release-APK. PR должен проходить сборку.

## Лицензирование вкладов

Отправляя Pull Request, вы соглашаетесь, что ваш вклад будет распространяться
под лицензией проекта — **GNU General Public License v3.0** (см. `LICENSE`).

## Сообщения об ошибках

Открывайте issue с описанием: что произошло, что ожидалось, шаги
воспроизведения, версия приложения (см. «О приложении») и модель/версия
Android. Логи можно приложить из экрана логов в настройках отладки.

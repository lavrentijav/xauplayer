# Структура файлов для индексации

Система автоматически индексирует аудиофайлы из папки `AUDIO_DIR` в формате:

```
AUDIO_DIR/
  Название серии/
    Том 1 Название тома/
      01.mp3
      02.mp3
      ...
      author.txt
      narrator.txt
      description.txt
      cover.jpg или cover.png
```

Система автоматически:
- Создает серию из названия папки первого уровня
- Создает книгу (том) из названия папки второго уровня
- Извлекает номер тома из названия (например, "Том 1" → series_order = 1)
- Индексирует все аудиофайлы как главы
- Определяет длительность глав через ffprobe
- **Помечает книги как скрытые (is_hidden=true)**, если они не найдены при индексации
- **Восстанавливает книги (is_hidden=false)**, если они снова появляются в файловой системе

## Скрытые книги

Книги, которые не найдены в файловой системе при индексации, автоматически помечаются как скрытые (`is_hidden=true`). Такие книги:
- Не возвращаются через API endpoints (GET `/books`, GET `/books/{book_id}`, и т.д.)
- Сохраняются в базе данных для возможного восстановления
- Автоматически восстанавливаются (`is_hidden=false`), если они снова появляются при следующей индексации

## Индексация

Индексация выполняется:
- При запуске сервера
- Автоматически при изменении файлов в `AUDIO_DIR` (через файловый watcher)

## Метаданные

### Файлы метаданных для книги:
- `author.txt` - Автор книги
- `narrator.txt` - Чтец
- `description.txt` - Описание книги
- `cover.jpg` или `cover.png` - Обложка книги

### Файлы метаданных для серии:
- `description.txt` - Описание серии (в папке серии)
- `cover.jpg` или `cover.png` - Обложка серии (в папке серии)

## Поддерживаемые форматы аудио

- `.mp3`
- `.m4a`
- `.wav`
- `.ogg`
- `.flac`
- `.aac`

## Порядок глав

По умолчанию порядок глав определяется по имени файла (сортировка по алфавиту). Для ручной корректировки порядка можно использовать endpoint `PUT /books/chapters/{chapter_id}/order` с параметром `real_order`.

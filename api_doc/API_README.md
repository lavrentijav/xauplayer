# API Документация - Audio Book Server

Полная документация API для сервера аудиокниг.

## Базовый URL

```
http://localhost:8000
```

## Аутентификация

Большинство endpoints требуют аутентификации через Bearer токен. Получите токен через `/auth/login` и используйте его в заголовке:

```
Authorization: Bearer <access_token>
```

## Коды ошибок

- `200` - Успешный запрос
- `400` - Неверный запрос
- `401` - Не авторизован
- `404` - Не найдено
- `500` - Внутренняя ошибка сервера

## Примечания

1. Все даты в формате ISO 8601 (YYYY-MM-DDTHH:MM:SSZ)
2. Длительность в секундах (float)
3. Позиция в миллисекундах (int)
4. Timestamp заметок в миллисекундах (int)
5. Статусы: `wanted`, `listening`, `completed`, `dropped`
6. При обновлении прогресса автоматически обновляется статистика пользователя

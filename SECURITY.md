# Политика безопасности

## Поддерживаемые версии

Обновления безопасности выпускаются для последней доступной версии
приложения. Пожалуйста, используйте актуальную сборку.

## Как сообщить об уязвимости

Не открывайте публичный issue для уязвимостей. Вместо этого напишите
сопровождающему проекта напрямую (через профиль GitHub
[@lavrentijav](https://github.com/lavrentijav)) с описанием проблемы и, по
возможности, шагами воспроизведения. Мы постараемся ответить в разумный срок и
скоординировать исправление и раскрытие.

## Секреты и ключи

- Ключ подписи APK **не** хранится в репозитории — только в GitHub Secrets
  (см. `.github/SIGNING.md`).
- `local.properties`, keystore-файлы и `.env` исключены через `.gitignore`.
